# Pool Limits

Кнопка-чип рядом с выбором модели в **Hermes Desktop**: показывает, сколько
процента **5-часового лимита** осталось у подписок, на которых работает
выбранная модель (среднее по живым аккаунтам семейства). Нажатие — панель со
всеми аккаунтами пула и окнами лимитов («5 часов», «Неделя», «Месяц») и
временем сброса.

## Что умеет

- **Пул CLIProxyAPI** на сервере Hermes: OAuth-аккаунты Codex и Claude, а также
  API-подписки:
  - **GLM / Zhipu** — подхватывается автоматически из `openai-compatibility`
    провайдера конфига CLIProxyAPI (хосты `api.z.ai` / `open.bigmodel.cn`),
    квоты читаются на `api.z.ai/api/monitor/usage/quota/limit`;
  - **Kimi (Kimi for Coding)** — ключ берётся из `KIMI_API_KEY` в `.env`
    Hermes на сервере, квоты читаются на `api.kimi.com/coding/v1/usages`.
- **Свои креды бэкенда Hermes** — статус активного провайдера.
- **Чип следует за моделью**: выбрана `glm-*` — показывает остаток GLM,
  `kimi-*` — остаток Кими, `gpt-*`/`claude-*` — соответствующие семейства.

## Установка

В Hermes Desktop: **Возможности → Плагины → Install from Git** →

```
https://github.com/Mirantaran/hermes-pool-limits
```

Отметьте обе галочки (**Плагин агента** и **Интерфейс Desktop**) → **Install**.
При повторной установке включите «Принудительная переустановка».

Требования: на сервере Hermes — работающий CLIProxyAPI и `python3`
(только стандартная библиотека).

## Приватность

Плагин строго read-only: читает auth-файлы пула и конфиги, ничего не пишет,
токены и ключи не печатаются и не покидают сервер хоста.
